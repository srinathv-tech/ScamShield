# ScamShield - 3-Minute Demo Script

Everything shown below exists in the prototype. Start with `npm start` and open http://localhost:5173.

**0:00-0:25 - The problem**
Say: "Scam messages are designed to rush people. This fictional one says a bank card will be blocked unless
you share an OTP. Many people do not know which parts are warning signs or what to do next."
Show the Check page.

**0:25-1:10 - Check the message**
Press "Try a fictional sample", then "Check on this device".
Point out: the label "High caution" and the words "Triage guidance, not a verdict"; the matched evidence
for each warning sign (secret code request, threat, urgency, trusted-name use); and the "Why this matters"
text under each one.

**1:10-1:40 - Safe next steps**
Scroll to "Safe next steps": do not share codes, do not transfer money because of urgency, verify through a
number or app you found yourself, never use contact details from the message. Then show "If money or codes
were already shared". Mention the line that a low-risk result never proves a message is legitimate.

**1:40-2:10 - Learn**
Open Learn. Open "Parcel redelivery fee", tick two signs, press "Reveal explanation" and read the key lesson.
Start the quiz, answer one question and show the instant feedback.

**2:10-2:35 - Incident checklist**
Open Checklist. Type a short description, choose where it happened, tick one step, and press "Copy summary".
Say: "This is built on the device. It is not sent to a server and not saved. ScamShield does not file complaints."
Optionally type a card-like number to show it is hidden in the summary.

**2:35-3:00 - Privacy, limits and workshops**
Open Privacy. Say: "Checks run locally, links are never opened, and nothing is stored unless you choose to save."
Be honest about limits: "It is a set of simple English rules, so it can miss scams and flag real messages.
It is a learning aid, not a detector. A community trainer could use the examples and quiz in a workshop."
